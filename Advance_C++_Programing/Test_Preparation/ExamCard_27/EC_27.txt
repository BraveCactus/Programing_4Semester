27. Абстрактный класс. Определение.
Определение: Класс, содержащий хотя бы одну чисто виртуальную функцию.

Особенности:

Нельзя создать экземпляр

Должен быть унаследован

Производные классы должны реализовать чисто виртуальные функции

cpp
class Abstract {
public:
    virtual void foo() = 0; // чисто виртуальная
};
