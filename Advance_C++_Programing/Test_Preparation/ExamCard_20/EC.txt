20. Что такое RVO? Пример?
RVO (Return Value Optimization): Оптимизация компилятора, позволяющая избежать лишнего копирования при возврате объекта из функции.

Пример:

cpp
std::string createString() {
    std::string s = "Hello";
    return s; // RVO позволяет избежать копирования
}

std::string str = createString(); // конструктор перемещения или даже конструктор напрямую
