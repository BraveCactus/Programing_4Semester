18. В каких случаях возникает двойная инициализация? Как избежать?
Двойная инициализация: Когда объект инициализируется дважды - сначала по умолчанию, затем присваиванием.

Пример:

cpp
class A {
    std::string s;
public:
    A(const std::string& s) : s(s) {} // хороший вариант
    A(const std::string& s) { this->s = s; } // двойная инициализация
};
Как избежать: Использовать списки инициализации.
