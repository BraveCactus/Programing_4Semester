// 8.	Алгоритм Флойда

Пошаговое объяснение:
Инициализация:

    Создаём матрицу расстояний n×n

    Заполняем диагональ нулями (расстояние от вершины к себе)

    Заполняем известные расстояния между смежными вершинами

Основная часть (тройной цикл):

    Внешний цикл (k) — промежуточная вершина

    Внутренние циклы (i, j) — пары вершин

    Для каждой пары (i, j) проверяем, будет ли путь через k короче

Результат:

    После выполнения матрица dist содержит кратчайшие расстояния между всеми парами вершин

void floydWarshall(int graph[][V]) {
    int dist[V][V];
    
    for (int i = 0; i < V; i++)
        for (int j = 0; j < V; j++)
            dist[i][j] = graph[i][j];
    
    for (int k = 0; k < V; k++) {
        for (int i = 0; i < V; i++) {
            for (int j = 0; j < V; j++) {
                if (dist[i][k] + dist[k][j] < dist[i][j])
                    dist[i][j] = dist[i][k] + dist[k][j];
            }
        }
    }
}
