16. Сужающие преобразованию и разные виды инициализации.
Сужающие преобразования:

Потеря точности (double → int)

Потеря данных (int → char)

Поведение при инициализации:

= и (): разрешают сужающие преобразования

{}: запрещают сужающие преобразования (ошибка компиляции)

cpp
int x = 3.14; // OK, сужение
int y(3.14); // OK, сужение
int z{3.14}; // ошибка, сужение запрещено
