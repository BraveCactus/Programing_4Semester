15. Когда не применима инициализация «в круглых скобках», «после =», «фигурная».
Круглые скобки:

Нельзя использовать для агрегатной инициализации

cpp
struct A { int x; int y; };
A a(1, 2); // ошибка
A a{1, 2}; // OK
После =:

Нельзя использовать для explicit конструкторов

cpp
class B {
    explicit B(int);
};
B b = 5; // ошибка
B b(5); // OK
Фигурные скобки:

Нельзя использовать с auto для вывода std::initializer_list

cpp
auto x = {1, 2}; // x - std::initializer_list<int>
