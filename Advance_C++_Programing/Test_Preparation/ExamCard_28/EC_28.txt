28. Использование аргументов со значениями по умолчанию в виртуальных функциях.
Особенность: Значения по умолчанию берутся из статического типа, а не динамического.

Пример:

cpp
class Base {
public:
    virtual void foo(int x = 1) { ... }
};

class Derived : public Base {
public:
    void foo(int x = 2) override { ... }
};

Base* b = new Derived;
b->foo(); // вызовется Derived::foo(1), а не Derived::foo(2)
