77. Пачки параметров. Как выделить паттерн раскрытия? Что такое свертки?
Пачка параметров (parameter pack): Набор типов или значений в шаблоне.

Раскрытие: Использование ... для применения операции к каждому элементу пачки.

Свертки (folds): Бинарные операции над пачками (C++17):

cpp
template <typename... Ts>
auto sum(Ts... args) {
    return (args + ...); // свертка
}
