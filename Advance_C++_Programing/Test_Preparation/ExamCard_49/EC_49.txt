49.	Манглирование имен. (Как перегрузки функций представляются компилятором)

Манглирование имён (Name Mangling) в C++
Манглирование имён (также известно как декорирование имён) — это процесс преобразования человеко-читаемых имён функций и переменных в уникальные внутренние имена, которые используются компилятором и линкером для корректной работы с перегрузкой функций, пространствами имён и другими особенностями C++.

Зачем нужно манглирование?
Поддержка перегрузки функций
В C++ можно иметь несколько функций с одним именем, но разными параметрами. Например:

cpp
void foo(int x);
void foo(double x);
Компилятор преобразует их в уникальные имена, например _Z3fooi и _Z3food.

Учёт пространств имён и классов

cpp
namespace MyLib {
    void bar();
}
Может превратиться в _ZN4MyLib3barEv.
